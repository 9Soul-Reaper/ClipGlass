# ClipGlass
ClipGlass —— 轻量优雅的 Windows 剪贴板管理工具  ClipGlass 是用 Go 原生开发的剪贴板增强工具，零依赖、单文件即可运行。玻璃拟态悬浮球常驻桌面，点击或快捷键唤出主面板，快速浏览、搜索历史剪贴板内容。  它自动将内容分类——文本、链接、代码、路径、颜色、图片、表格等十余种类型，支持置顶与彩色分组管理；可一键识别邮箱、网址、路径，快速打开或发邮件，还能粘贴为纯文本、大小写转换。  内置敏感信息检测，自动识别私钥、API Key、密码、验证码、证件号等，支持剪贴板暂停、排除规则与密码锁，数据全部本地存储。  另有深浅色主题、14 种界面语言、开机自启、自动粘贴、导出备份等设置，内存占用极低。无论是办公还是开发，ClipGlass 都让复制粘贴更高效、更优雅。
