ClipGlass 是一款用 Go 从零写成的 **Windows 剪贴板历史管理工具**。它没有套 Electron，没有带运行时，整个程序就是一个小小的 `.exe`：双击即用，常驻托盘，按快捷键呼出，一块毛玻璃质感的浮窗从鼠标旁滑出——你最近复制过的文字、链接、代码、图片，全都排在里面，点一下就回到剪贴板，直接粘走。

## 📦 下载（二选一即可）

| 文件 | 体积 | 适合谁 |
|---|---|---|
| [ClipGlass-1.0.2.exe](./ClipGlass-1.0.2.exe) | 约 1.0 MB | **大多数人选这个**（精简版，体积小，功能完整） |
| [ClipGlass-1.0.2-full.exe](./ClipGlass-1.0.2-full.exe) | 约 3.3 MB | 杀毒软件对精简版误报时，换这个（full 版） |

**怎么选？** 很简单：

- 正常情况下，**下载 `ClipGlass-1.0.2.exe`（精简版）就好**——它足够小、足够快，功能与 full 版完全一致。
- 如果你的杀毒软件（Windows Defender、360、火绒等）对精简版报了"可疑文件"，别慌，那是加壳/压缩工具常见的误报。这时请改下 **`ClipGlass-1.0.2-full.exe`**，它未做体积压缩，误报率低得多。

两个版本解压即用（其实根本不用解压），不需要安装，不需要管理员权限，删掉 exe 就是卸载。

## 🚀 快速上手

1. 双击运行 `ClipGlass-1.0.2.exe`，托盘区多出一枚小图标；
2. 复制任何东西（Ctrl+C 截图、选中文本复制、复制文件……都行）；
3. 按呼出快捷键（可在设置里自定义，需包含 Ctrl / Alt / Shift / Win 之一），玻璃浮窗出现；
4. 直接打字搜索、鼠标点选、方向键 + 回车皆可，条目自动回到剪贴板并粘贴；
5. 右键托盘图标可以暂停记录、打开数据文件夹、清空历史、退出。

支持 **Alt + 数字** 快选前几条，复制 → 呼出 → 按键 → 粘贴，一气呵成。

## ✨ 功能一览

### 📋 智能记录
- **什么都能记**：纯文本、富文本、URL、文件路径、图片，统统进历史；
- **自动分类**：链接、代码、联系方式（邮箱/电话）、路径、数字、图片自动打上小标签，顶部芯片一点就筛；
- **置顶**：常用的命令、账号、模板钉在最上面，永远不沉底。

### 🔍 极速查找
- 浮窗打开即可**盲打搜索**，无需先点搜索框；
- 上限默认 500 条，保留期默认 30 天，均可调整（0 = 永久保存）。

### 🔒 隐私优先
- **密码/密钥智能识别**：识别出 API Key、口令类内容时可自动不记录或定时销毁，敏感内容不进备份；
- 历史数据使用 **Windows DPAPI** 加密落盘，绑定当前用户账户；
- 支持忽略指定程序（密码管理器等）的复制内容；可一键暂停记录；
- **离线运行**：没有任何网络请求，你的剪贴板只属于你。

### 🗂️ 分组与整理
- 自建分组、自定义颜色、重命名、拖拽归类；
- 右键任意条目：粘贴 / 复制 / 纯文本粘贴 / 大小写转换 / 打开链接 / 揭示文件 / 发邮件 / 置顶 / 忽略来源 / 删除。

### 🎨 好看又顺手
- 毛玻璃（Acrylic/Blur）质感浮窗，深色 / 浅色主题 + 多种主题色；
- 界面缩放、动画开关、弹窗位置（鼠标旁 / 屏幕中央 / 记忆位置）随你调；
- 桌面**悬浮小球**（可开关），不呼快捷键也能一键唤出主窗。

### 🌍 多语言
内置 **14 种语言**：简体中文、English、繁體中文、日本語、한국어、Español、Français、Deutsch、Português、Русский、Italiano、Türkçe、Tiếng Việt、Bahasa Indonesia，默认跟随系统语言。

### ⚙️ 其他贴心项
- 开机自启（静默进托盘）；
- 自动粘贴开关（关掉则只复制不粘贴）；
- 数据可导出备份，方便迁移。
