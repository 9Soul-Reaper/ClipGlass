# ClipGlass 1.0.1

**Windows 剪贴板,理应有更好的记性。**

你一定经历过这种时刻:五分钟前复制的那段配置被新内容顶掉了,只能翻聊天记录找回;截图贴出去之前忘了留底,只好重截一遍。Windows 自带的 `Win+V` 能记,但记不住分区、认不出密码、界面也谈不上好看。

ClipGlass 是为此而生的小工具:毛玻璃质感的剪贴板历史面板,纯 Go 标准库手写界面,不依赖任何第三方库,**整个程序就一个 `ClipGlass.exe`(约 3.5 MB)**——双击即用,无需安装,不联网,不注册服务,不留注册表垃圾。不用了?删掉 exe 和数据文件夹,干干净净。

---

## 30 秒上手

1. 双击 `ClipGlass.exe`,托盘区安静地多出一个图标。
2. 照常复制任何东西——文本、图片、文件,一条不落。
3. 按 **Ctrl+Shift+V**(默认热键,可改)或点击屏幕边缘的悬浮球,毛玻璃面板在鼠标旁展开。
4. 点击任意条目,内容回到剪贴板并自动粘贴进原窗口——完成。

就这么多。它不要求你改变任何习惯,只是让你复制过的东西不再消失。

## 功能一览

### 📋 历史记录,该记的都记
- 文本、图片(含缩略图)、文件列表统一收录,自动去重:再复制一次同样的内容,它会被顶回最上面而不是产生重复条目。
- 顶部搜索框即输即筛,还有类型芯片一键过滤:**文本 / 链接 / 路径 / 数字 / 图片 / 置顶**,以及你自己建的分区。
- **置顶(Ctrl+P)**常用内容,清空历史时置顶项不会被误删。
- 默认保留 **30 天、最多 500 条**,都可在设置中调整;过期和超限的条目连同图片文件一起被清理,不悄悄占你的磁盘。

### 📁 自定义分区
给高频内容安个家:工作片段、常用回复、代码模板……把条目拖进分区,以后按分区直达。分区随备份一起导出。

### 🎯 悬浮球
一颗会贴边的小球:拖到哪里,松手后自动吸附到最近的屏幕左右边缘并记住位置。单击呼出面板,再点隐藏,不挡事也不碍眼。

### ⌨️ 全键盘流
面板里不需要鼠标:
- `↑` `↓` 选择,`Enter` 粘贴
- `Alt+1~9` 快速取用前九条
- `Del` 删除,`Ctrl+P` 置顶
- 呼出热键、暂停/恢复记录热键都可在设置中自定义(组合键被占用会明确提示)

### 🛡️ 敏感内容识别
剪贴板是密码泄露的重灾区——多少人复制完密码忘了清。ClipGlass 内置文本识别,能认出 **API 密钥、令牌、私钥、JWT、数据库连接串、`password=` 行、验证码、银行卡号、证件号、随机密码**等,并提供三档处理:

| 档位 | 行为 |
| --- | --- |
| 跳过不记录(默认) | 敏感内容根本不进历史,还会清掉历史里已有的同内容 |
| 仅内存保留 10 分钟 | 短暂可用,**永不写盘**,也不进备份,10 分钟后自动消失 |
| 不过滤 | 全部照记 |

另外:密码管理器输出的内容(它们声明"不进入剪贴板历史")和已知密码管理器进程默认被忽略。图片和文件列表不做检测;识别可能漏报或误报,请如实理解。

### 🌐 14 种语言
简体中文、English、繁體中文、日本語、한국어、Español、Français、Deutsch、Português、Русский、Italiano、Türkçe、Tiếng Việt、Bahasa Indonesia。默认跟随系统语言,可手动切换,每种语言都配了合适的界面字体。

### 🎨 毛玻璃与外观
毛玻璃不是系统特效,而是 ClipGlass 自己实现的——截取窗口后方的桌面,实时模糊成背景。主题、强调色、透明度、界面缩放、动画都可在设置里调;窗口出现位置可选鼠标旁 / 屏幕中央 / 记住上次位置。

### 💾 备份与恢复
设置 → 隐私与数据 → **完整备份**,一键导出 zip(历史、图片、分区、设置;敏感内存条目不会混进去)。恢复时把 zip 改名 `import.zip` 放进数据文件夹,点"导入备份"——先预览会新增多少条,再点一次才真正导入。合并式恢复:已存在的内容跳过、分区按名称合并,**绝不覆盖现有数据**。

## 数据在哪里?

数据目录:`%APPDATA%\ClipGlass`(设置里"打开数据文件夹"一键直达)

| 文件 | 内容 |
| --- | --- |
| `history.json`(+`.bak`) | 历史条目,带版本号 `{"v":1,"items":[…]}`;每次写入先保留上一版为 `.bak`,主文件损坏会自动回退并把坏文件存为 `history.corrupt-*.json` |
| `groups.json` | 自定义分区 |
| `images/` | 图片及缩略图(PNG) |
| `settings.json` | 设置 |

## 隐私,请如实了解

- **不做任何网络请求。**没有账号,没有遥测,没有"匿名统计"。
- **默认明文保存**:历史是明文 JSON,躺在你的用户目录里。可在设置中开启"加密保存历史"(Windows DPAPI,绑定当前 Windows 账户,覆盖历史、图片与缩略图)。注意:换账户或重装系统后加密数据无法读取;**完整备份 zip 始终是明文**。
- 界面没有"密码锁"。想防止他人查看,请开启加密并使用 Windows 账户锁屏。
- **自动粘贴**会在选中条目后向原窗口发送 Ctrl+V;介意的话可在设置中关闭(关闭后仅复制到剪贴板),首次使用后也会提示一次。

## 已知限制

- Win32 层(窗口、热键、托盘、剪贴板、悬浮球)只能在 Windows 上验证;CI 目前只覆盖编译与模型层测试。
- 不支持从右到左书写的语言(如阿拉伯语)。
- 毛玻璃是自实现模糊,拖动窗口后松手才会刷新背景。

## 系统要求与安装

Windows 10 / 11(x64)。下载 `ClipGlass.exe`,放到任意喜欢的位置,双击运行。想开机自启?设置里勾选"随 Windows 启动",它在托盘里安静守着,不弹窗不抢焦点。
